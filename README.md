# 육아휴직·단축근무 정산 계산기

퇴사자를 위한 자가 점검 계산기입니다. 외부 라이브러리·CDN·빌드 도구 없이 정적 파일 3개로 동작하고,
입력값은 브라우저 밖으로 나가지 않습니다.

**법적 성격**: 2026년 공개 법령 기준의 자가 점검용 참고 계산기이며, 개별 사건의 법적 판단·서류 작성 대행이
아닙니다. 실제 청구·진정은 관할 고용노동지청·고용센터·공인노무사를 통해 확인해야 합니다.
(공인노무사법 제27조 — 유상 노무상담·서류 작성 대행 금지)

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면(입력 폼 · 결과 · 이직확인서 4칸 점검 · 신청 방법/안내처 · 진정 체크리스트) |
| `styles.css` | 스타일 (모바일 우선, 360px 기준, 인쇄용 스타일 포함) |
| `app.js` | 계산식과 화면 동작. `window.Calc`로 계산 함수 노출 |

## 화면 구성

1. **입력** — 기본 정보(퇴직급여 제도 포함) · 육아휴직 기간(최대 3개) · 육아기 단축근무(시간/일수 단축) · 연차 · 실업급여 · 이직확인서 기재 내용
2. **결과** — 5가지 정산 항목 카드, 실업급여는 ①신고 기준 / ②단축 전 기준을 나란히 표시
3. **이직확인서 4칸 점검** — 이직사유 · 피보험단위기간 · 평균임금 · 1일 소정근로시간을 자동 대조하고 정정 절차 안내
4. **신청 방법과 담당 안내처** — 1350 · 고용24 · 노동포털 · 근로복지공단 · 대한법률구조공단
5. **진정 준비** — 절차, 증빙 체크리스트, 벌칙·시효 안내

## 배포

폴더째 올리면 됩니다. 상대경로(`styles.css`, `app.js`)만 쓰므로 하위 경로·커스텀 도메인 모두 그대로 동작합니다.

- **GitHub Pages**: 저장소에 폴더 내용을 올리고 Settings → Pages에서 브랜치/루트 지정
- **Cloudflare Pages**: 프로젝트 생성 시 빌드 명령 없이 출력 디렉터리를 이 폴더로 지정
- **Netlify**: 폴더를 드래그&드롭
- **일반 웹서버**: 폴더를 웹 루트에 복사

## 링크 자리 바꾸기

`index.html` 하단 `#link-slot-guide` 블록은 가이드북·크몽 링크용 자리입니다.

```html
<div class="link-slot" id="link-slot-guide" hidden>
```

`hidden`만 지우고 `#link-guide`의 `href`를 실제 주소로 바꾸면 카드가 나타납니다.

| 항목 | 근거 |
| --- | --- |
| 육아휴직 기간 출근 간주(연차) | 근로기준법 제60조 제6항 제3호 (2018.5.29 이후 개시분) |
| 단축근무 기간 출근 간주(연차) | 근로기준법 제60조 제6항 제4호 (2024.10.22 이후 개시분) |
| 육아휴직 기간 근속 포함 | 남녀고용평등법 제19조 제4항 |
| 육아휴직 기간 평균임금 제외 | 근로기준법 시행령 제2조 제1항 제5호 |
| 단축근무 기간 평균임금 제외 | 남녀고용평등법 제19조의3 제4항 |
| 평균임금 < 통상임금이면 통상임금 (단축 전 소정근로시간 기준) | 근로기준법 제2조 제2항 |
| 상여금·연차수당 가산(3/12) | 근로기준법 시행령 제2조 제2항 |
| 단축 시간 초과근무 50% 가산 | 기간제법 제6조 제3항, 남녀고용평등법 제19조의3 제3항(주 12시간 한도) |
| 구직급여 = 기초일액 × 60%, 최저기초일액 = 최저임금 × 80% × 1일 소정근로시간 | 고용보험법 제45조·제46조 |
| 2026년 이직자 상한 68,100원 / 하한 66,048원(8시간) | 고용보험법 시행령, 2026년 최저임금 10,320원 |
| 2025년 이직자 상한 66,000원 / 하한 64,192원(8시간) | 고용보험법 시행령, 2025년 최저임금 10,030원 |
| 퇴직급여 체불 벌칙 | 근로자퇴직급여 보장법 제43조(2026.9.18 시행, 5년/5천만원) |
| 임금·수당 체불 벌칙 | 근로기준법 제107조(2026.10.8 시행, 5년/5천만원) |
| 간이대지급금 | 임금채권보장법 — 진정 1년 내, 확인서 최초 발급일부터 6개월 내 청구, 합계 1,000만원 |

연도가 바뀌면 `app.js`의 `RULES.years`(최저임금·구직급여 상한·기초일액 상한)와 `index.html` 상단 기준 문구를 갱신하세요.
`RULES.years`에 없는 해는 가장 가까운 해 기준으로 계산하고, 화면에 경고를 띄웁니다.

## 계산식 요약

- 1일 통상임금 = 월 급여 ÷ 월 소정근로시간 × 1일 소정근로시간
  - 월 소정근로시간 = (주 소정근로시간 + 주휴시간) × 365 ÷ 12 ÷ 7
  - 주휴시간 = min(8, 주 소정근로시간 ÷ 40 × 8), 주 15시간 미만이면 0 → 주 4일(32시간)이면 6.4시간, 월 167시간
- 평균임금 산정기간 = 이직일 포함 직전 3개월(91일)에서 휴직·단축기간을 뺀 기간.
  3개월이 모두 제외기간이면 그 기간 직전 3개월로 이동.
- 1일 평균임금 = max(산정기간 임금총액 ÷ 산정일수, 1일 통상임금)
- 퇴직금 = 1일 평균임금 × 30일 × 재직일수 ÷ 365일
- 연차수당 = 미사용 연차일수 × 1일 통상임금
- 초과근무 가산수당 = 시간 × 단축 중 통상시급 × 150% − 이미 받은 수당
- 구직급여 1일액 = min(상한, max(최저임금 × 80% × 1일 소정근로시간, 기초일액 × 60%))
  - ① 이직확인서에 적힌 시간·금액 기준 ② 단축 전 소정근로시간 기준을 각각 계산해 차액을 보여 줌
- 1년 미만 연차 = 1개월 개근 시 1일(최대 11일). 1년이 되는 날 전날까지는 11일.
